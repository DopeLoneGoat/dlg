# Домашнее задание к работе 8

## Условие задачи

Вычислите для заданного натурального n и действительного х с использованием цикла for значение.
sinx+sin(sinx)+...+sin(sin(...sinx)). n - количество раз

## 1. Алгоритм и блок-схема

### Алгоритм решения
1. **Начало**
2. Объявить переменные:
   - `n` (целочисленная, для количества шагов)
   - `x` (вещественная, для аргумента и текущего значения)
   - `sum` (вещественная, для накопления суммы, инициализируется 0)
3. Задать исходные данные (ввод с клавиатуры):
   - n
   - x
4. Запустить цикл `for (int i = 1; i <= n; i++)`:
   - Вычислить новый синус: `x = sin(x);`
   - Прибавить результат к сумме: `sum += x`
5. Вывести значение `sum`.
6. **Конец**
