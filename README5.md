## Условие задачи

Вычислить значение выражения `w` по заданной формуле. Результат проверить при заданных исходных значениях.

**Формула:**
w = |x|^(y/x) - ∛(y/x) + (y - x) * (cos(y) - z/(y-x)) / (1 + (y-x)^2)

**Контрольный пример:**
- x = 1.825 * 10^2
- y = 18.225
- z = -3.298 * 10^2
(Ожидаемый ответ из методички: 1.2131)
