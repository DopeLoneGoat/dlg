# Домашнее задание к работе 4

## Условие задачи

На развилке дорог стоит знак. Он показывает направление "Налево", если только одно из двух чисел (A или B), полученных от датчиков traffic flow, является четным. Запишите условие для показа направления "Налево".

## 1. Алгоритм и блок-схема

### Алгоритм решения
1. **Начало**
2. Объявить переменные:
   - `A`, `B` (целочисленные, для входных данных)
3. Задать исходные данные (ввод с клавиатуры):
   - A
   - B
4. Проверить условие: является ли **ровно одно** из чисел четным.
   - Условие: `(A % 2 == 0) != (B % 2 == 0)`
5. Если условие истинно (Да) — вывести: `Направление: Налево`
6. Если условие ложно (Нет) — ничего не выводить.
7. **Конец**
