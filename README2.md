# Домашнее задание к работе 2

## Условие задачи

Написать и отладить программу пересчета заданного в
секундах временного интервала в часы и минуты;

## 1. Алгоритм и блок-схема

### Алгоритм решения

1. Начало

2. Объявить константы (исходные данные):
   * секунды - общее количество секунд (целое число).
   * часов, минут, секунд - для хранения результатов пересчета (целые числа).

3. Задать исходные данные:
   * Ввести с клавиатуры значение переменной "секунды".

4. Проверить корректность данных:
   * Если "секунды" < 0, вывести сообщение об ошибке и завершить программу.

5. Вычислить количество часов:
   * часов = секунды / 3600

6. Вычислить остаток секунд после вычитания часов:
   * остаток = секунды % 3600

7. Вычислить количество минут:
   * минут = остаток / 60

8. Вычислить оставшееся количество секунд:
   * секунд = остаток % 60

9. Вывести результаты расчетов с подстановкой всех значений в текст.

10. Конец
